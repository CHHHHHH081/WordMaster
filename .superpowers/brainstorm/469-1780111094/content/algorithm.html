📐 SM-2 改良算法公式

质量评分 q（0-5）
5完美回答，秒答
4正确，稍作思考
3正确，但有明显犹豫
2错误，但看到答案后记得
1错误，看到答案也模糊
0完全不记得
核心公式（TypeScript 伪代码）
function calculateNextReview(progress, quality) {
// q < 3: 答错了，重置间隔
if (quality < 3) {
progress.repetitions = 0;
progress.intervalDays = 1;
return;
}

// 更新 Ease Factor
progress.easeFactor +=
0.1 - (5-quality)*(0.08 + (5-quality)*0.02);
progress.easeFactor = max(1.3, progress.easeFactor);

// 计算下次间隔
if (repetitions === 0) interval = 1
else if (repetitions === 1) interval = 6
else interval = prevInterval * easeFactor;

progress.repetitions++;
progress.intervalDays = interval;
progress.nextReviewAt = now + interval * day;
}

🔧 我们的改良点

⏱️ 答题时间加权

秒答 (0-3s)：EF 额外 +0.1
正常 (3-10s)：标准计算
犹豫 (>10s)：EF 额外 -0.1
答对但犹豫 = 掌握不牢

🎯 模式权重

选择题答对 → EF 增长较小 (×0.8)
拼写答对 → EF 增长较大 (×1.2)
拼写正确比选择更说明掌握

🔄 弹性复习窗口

到期当天：优先展示
提前复习：不惩罚，正常计算
逾期 1-3 天：EF 微降 (×0.95)
逾期 >7 天：重置间隔
