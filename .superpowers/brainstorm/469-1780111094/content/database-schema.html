Database Schema — 数据模型设计

Prisma + SQLite，6 张核心表

实体关系图 (ERD)

👤 User
id : int (PK)
email : string (unique)
username : string
passwordHash : string
createdAt : datetime
📚 WordBank
id : int (PK)
name : string
description : string
wordCount : int
User ──has many──▶ UserWordProgress ◀──belongs to── Word
                                               │
                                               WordBank ──has many── Word
                                               User ──has many── StudySession
                                               Word ──has many── ReviewLog
📝 Word
id : int (PK)
wordBankId : int (FK)
word : string
phonetic : string
partOfSpeech : string
definition : string
exampleSentence : string
📊 UserWordProgress
id : int (PK)
userId : int (FK, unique with wordId)
wordId : int (FK, unique with userId)
stage : enum (new|learning|review|mastered)
easeFactor : float (default 2.5)
intervalDays : int (default 0)
repetitions : int (default 0)
nextReviewAt : datetime
correctCount : int
incorrectCount : int
📅 StudySession
id : int (PK)
userId : int (FK)
wordBankId : int (FK)
mode : enum (flashcard|choice|spelling)
startedAt : datetime
endedAt : datetime
wordsStudied : int
correctCount : int
📋 ReviewLog
id : int (PK)
userId : int (FK)
wordId : int (FK)
mode : enum
isCorrect : bool
answeredAt : datetime
timeSpentMs : int

核心字段说明

🧠 UserWordProgress — 间隔复习引擎
  • stage: new → learning → review → mastered，追踪学习阶段
  • easeFactor: 难度系数，答对升高答错降低（默认 2.5）
  • intervalDays: 下次复习间隔天数（1, 2, 4, 7, 15, 30...）
  • nextReviewAt: 下次复习时间，到期提醒用户
📈 StudySession + ReviewLog — 学习分析
  • StudySession: 每次学习的汇总记录
  • ReviewLog: 每个单词的答题明细
  • 配合可生成：正确率趋势、学习时长、薄弱词分析
